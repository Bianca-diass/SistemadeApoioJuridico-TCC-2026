
# Sistema de Apoio Jurídico Digital – TCC 2026

Sistema web desenvolvido como Trabalho de Conclusão de Curso (TCC), com o objetivo de facilitar a gestão jurídica e melhorar a comunicação entre advogados e clientes.

## Funcionalidades

- Cadastro e gerenciamento de advogados e clientes.
- Cadastro, consulta e acompanhamento de processos jurídicos.
- Dashboard exclusivo para advogados e clientes.
- Compartilhamento e gerenciamento de documentos.
- Upload de documentos em PDF.
- Agenda de compromissos e audiências.
- Exibição automática de processos e compromissos no dashboard do cliente.
- Sistema de notificações.
- Relatórios de atividades.
- Autenticação e controle de acesso.
- Integração com Supabase.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js

- Supabase

## Instalação e execução

1. Clone o repositório:

```bash
git clone https://github.com/Bianca-diass/SistemadeApoioJuridico-TCC-2026.git
```

2. Entre na pasta do projeto:

```bash
cd SistemadeApoioJuridico-TCC-2026
```

3. Instale as dependências:

```bash
npm install
```

4. Configure as variáveis de ambiente necessárias para a conexão com o Supabase.

5. Inicie o backend:

```bash
npm start
```

## Etapa 6 – Atualização e integração do sistema

Nesta etapa foram realizadas melhorias e atualizações gerais no sistema, incluindo:

- Integração dos processos cadastrados pelo advogado com o dashboard do cliente.
- Sincronização dos compromissos da agenda com o dashboard do cliente.
- Melhorias no gerenciamento de clientes e processos.
- Atualizações na gestão e compartilhamento de documentos.
- Implementação e atualização de serviços, controladores e rotas do backend.
- Melhorias na autenticação e identificação dos clientes.
- Ajustes nas interfaces das áreas do advogado e do cliente.

## Objetivo do projeto

Desenvolver uma plataforma digital que auxilie advogados na organização de suas atividades jurídicas e permita aos clientes acompanhar seus processos, documentos e compromissos de maneira prática, organizada e acessível.
