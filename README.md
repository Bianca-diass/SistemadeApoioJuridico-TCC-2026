# Sistema de Apoio Jurídico (TCC 2026)

Sistema completo de apoio jurídico desenvolvido para conectar e auxiliar advogados e clientes, abrangendo a gestão de processos, clientes, documentos e agenda. Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC).

## 🚀 Tecnologias

* **Node.js / JavaScript** (Gestão de dependências e scripts)
* **FrontEnd**: Interface de utilizador
* **Backend**: Serviços e API de gestão de dados

## 📁 Estrutura do Projeto

* `FrontEnd/` - Interface web/mobile para advogados e clientes.
* `backend/` - Regras de negócio, autenticação, gestão de processos e integração com a base de dados.
* `package.json` - Configurações e dependências do projeto.
